# classical-text-representation

Enfoques clásicos de representación de texto para PLN: Bolsa de Palabras, TF-IDF, n-gramas, Fastext, Wor2Vec





\## Datos



Este repositorio no incluye los datos de TASS 2018 por razones de licencia y reproducibilidad.



Para ejecutar el notebook, coloca los siguientes archivos en las rutas indicadas (no se versionan en git):



\- `data/tass/tass2018\_es\_train.csv`

\- `data/tass/tass2018\_es\_test.csv`



Los datos se obtienen de  : \https://github.com/EdwinPuertas/courseNLP/tree/main/examples/data/tass.



\## Reproducibilidad



\- Semillas fijas (`random\_state`/`SEED`) en todas las celdas de particionamiento y entrenamiento.

\- Ejecutar el notebook de inicio a fin sin modificar rutas relativas.
